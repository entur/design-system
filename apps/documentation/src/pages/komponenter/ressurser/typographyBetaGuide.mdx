# Typography Beta - Komplett Guide

## Introduksjon

Typography Beta er vår nye tilnærming til typografiske komponenter. Vi har forenklet fra mange spesifikke komponenter til to fleksible hovedkomponenter: `<Heading>` og `<Text>`. Dette gir større fleksibilitet og bedre tilgjengelighet.

### Hovedprinsipper

1. **Variants er anbefalt tilnærming** - Bruk `variant` for størrelse og spacing
2. **Heading er "strengere"** - Automatisk mapping fra `as` til `variant`
3. **Text er mer fleksibel** - Ingen automatisk mapping, du velger selv
4. **Semantikk og visuell styling er separert** - Bruk `as` for semantikk, `variant` for utseende

---

## Heading-komponenten

### Hvorfor er Heading "strengere"?

Heading-komponenten har automatisk mapping fra semantiske HTML-elementer (`as`) til visuelle varianter (`variant`). Dette betyr at:

- `<Heading as="h1">` gir automatisk `variant="title-1"`
- `<Heading as="h2">` gir automatisk `variant="title-2"`
- `<Heading as="h3">` gir automatisk `variant="subtitle-1"`
- `<Heading as="h4">` gir automatisk `variant="subtitle-2"`

**Fordel:** Heading får alltid riktig styling basert på semantikken, noe som sikrer konsistens.

### Automatisk mapping

````jsx
// Disse gir automatisk riktig styling:
<Heading as="h1">Hovedtittel</Heading>
<Heading as="h2">Undertittel</Heading>
<Heading as="h3">Seksjonstittel</Heading>
<Heading as="h4">Subseksjonstittel</Heading>
````

### Manuell variant-overstyring

Du kan alltid overstyre den automatiske mappingen:

````jsx
// H1 med mindre styling
<Heading as="h1" variant="subtitle-1">H1 som ser ut som subtitle</Heading>

// H2 med større styling  
<Heading as="h2" variant="title-1">H2 som ser ut som hovedtittel</Heading>
````

### Tilgjengelige varianter

````jsx
<Heading as="h1" variant="title-1">Title 1</Heading>
<Heading as="h2" variant="title-2">Title 2</Heading>
<Heading as="h3" variant="subtitle-1">Subtitle 1</Heading>
<Heading as="h4" variant="subtitle-2">Subtitle 2</Heading>
<Heading as="h5" variant="section-1">Section 1</Heading>
<Heading as="h6" variant="section-2">Section 2</Heading>
````

## Text-komponenten

### Hvorfor er Text mer fleksibel?

Text-komponenten har **ingen automatisk mapping** fra `as` til `variant`. Dette betyr at:

- `<Text as="p">` gir **ikke** automatisk `variant="paragraph"`
- `<Text as="label">` gir **ikke** automatisk `variant="label"`
- Du må eksplisitt velge `variant` for å få riktig styling

**Fordel:** Maksimal fleksibilitet - du kan bruke hvilken som helst kombinasjon av `as` og `variant`.

### Eksempler på fleksibilitet

````jsx
// P-element med paragraph-styling
<Text as="p" variant="paragraph">Dette er en paragraf</Text>

// P-element med caption-styling
<Text as="p" variant="caption">Dette ser ut som en caption</Text>

// Span-element med label-styling
<Text as="span" variant="label">Dette ser ut som en label</Text>

// Label-element med paragraph-styling
<Text as="label" variant="paragraph">Dette ser ut som en paragraf</Text>
````

### Tilgjengelige varianter

````jsx
<Text variant="leading">Leading tekst</Text>
<Text variant="quote">Quote tekst</Text>
<Text variant="paragraph">Paragraph tekst</Text>
<Text variant="subparagraph">Subparagraph tekst</Text>
<Text variant="caption">Caption tekst</Text>
<Text variant="label">Label tekst</Text>
<Text variant="sublabel">SubLabel tekst</Text>
<Text variant="overline">Overline tekst</Text>
````

### Størrelser og vekter

````jsx
// Størrelser
<Text size="xl">Extra Large</Text>
<Text size="lg">Large</Text>
<Text size="m">Medium</Text>
<Text size="s">Small</Text>
<Text size="xs">Extra Small</Text>

// Vekter
<Text weight="bold">Bold tekst</Text>
<Text weight="semibold">Semibold tekst</Text>
<Text weight="medium">Medium tekst</Text>
<Text weight="regular">Regular tekst</Text>
````

## Spacing-systemet

### Ny tilnærming: "Legg til" istedenfor "fjern"

Det gamle `margin`-systemet var forvirrende - det "fjernet" margins. Det nye `spacing`-systemet "legger til" spacing, noe som er mer intuitivt.

### Spacing-tokens

Vi bruker våre eksisterende spacing-tokens fra designsystemet:

- `xs2` - Ekstra liten spacing (ny!)
- `xs` - Liten spacing
- `sm` - Small spacing
- `md` - Medium spacing (standard)
- `lg` - Large spacing
- `xl` - Extra large spacing

### Retningsbestemt spacing

Du kan spesifisere spacing i spesifikke retninger:

- `spacing="md"` - Spacing over og under
- `spacing="md-top"` - Kun spacing over
- `spacing="md-bottom"` - Kun spacing under

### Eksempler

````jsx
// Standard spacing (md)
<Heading as="h2" spacing="md">Standard overskrift</Heading>
<Text variant="paragraph" spacing="md">Standard paragraf</Text>

// Liten spacing
<Heading as="h3" spacing="sm">Kompakt overskrift</Heading>
<Text variant="caption" spacing="sm">Kompakt caption</Text>

// Stor spacing
<Heading as="h1" spacing="lg">Stor overskrift med mye luft</Heading>
<Text variant="leading" spacing="lg">Leading tekst med mye luft</Text>

// Ingen spacing
<Heading as="h4" spacing="none">Overskrift uten spacing</Heading>
<Text variant="label" spacing="none">Label uten spacing</Text>

// Retningsbestemt spacing
<Heading as="h2" spacing="lg-top">Overskrift med mye luft over</Heading>
<Text variant="paragraph" spacing="sm-bottom">Paragraf med liten luft under</Text>

// Ny xs2 spacing
<Text variant="caption" spacing="xs2">Ekstra kompakt caption</Text>
<Text variant="label" spacing="xs2-top">Label med liten luft over</Text>
````

## Sammenligning: Heading vs Text

| Egenskap | Heading | Text |
|----------|---------|------|
| **Automatisk mapping** | ✅ Ja - `as="h1"` → `variant="title-1"` | ❌ Nei - du velger selv |
| **Stricthet** | Streng - alltid riktig styling | Fleksibel - uendelige kombinasjoner |
| **Anbefalt bruk** | Overskrifter og titler | Brødtekst og andre tekstelementer |
| **Semantikk** | Automatisk korrekt | Du må tenke på det selv |
| **Styling** | Følger automatisk semantikken | Uavhengig av semantikken |

## Beste praksis

### 1. Bruk variants som hovedtilnærming

````jsx
// ✅ Anbefalt - bruk variant
<Heading as="h1" variant="title-1">Tittel</Heading>
<Text variant="paragraph">Paragraf</Text>

// ❌ Unngå - bruk size direkte
<Heading as="h1" size="2xl">Tittel</Heading>
<Text size="m">Paragraf</Text>
````

### 2. Tenk semantikk først

````jsx
// ✅ Riktig - semantisk korrekt
<Heading as="h1">Hovedtittel</Heading>
<Heading as="h2">Undertittel</Heading>
<Text as="p" variant="paragraph">Paragraf</Text>

// ❌ Feil - misbruk av semantikk
<Heading as="h6">Hovedtittel</Heading>
<Text as="h1" variant="paragraph">Paragraf</Text>
````

### 3. Bruk spacing konsistent

````jsx
// ✅ Konsistent spacing
<Heading as="h1" spacing="lg">Tittel</Heading>
<Text variant="leading" spacing="md">Ingress</Text>
<Text variant="paragraph" spacing="sm">Paragraf</Text>

// ❌ Inkonsistent spacing
<Heading as="h1" spacing="xl">Tittel</Heading>
<Text variant="leading" spacing="xs">Ingress</Text>
<Text variant="paragraph" spacing="lg">Paragraf</Text>
````

## Display Mode

Typography Beta støtter forskjellige visningsmoder for å tilpasse typografien til ulike skjermstørrelser og bruksområder.

### Hvordan det fungerer

Systemet bruker `display-mode` attributtet for å kontrollere typografi-skalering:

- **Default/Mobile**: Responsiv typografi som tilpasser seg skjermstørrelse
- **Large**: Forstørret typografi for store skjermer, kiosker, eller tilgjengelighet

### Bruk av display-mode

#### HTML-nivå (anbefalt for hele siden)

```html
<html display-mode="large">
  <!-- Alt innhold får large typografi -->
</html>
```

#### Komponent-nivå (for spesifikke seksjoner)

```html
<div display-mode="large">
  <Heading as="h1">Stor tittel for store skjermer</Heading>
  <Text variant="paragraph">Større tekst som er lettere å lese</Text>
</div>
```

#### JavaScript (dynamisk endring)

```javascript
// Sett display mode for hele siden
document.documentElement.setAttribute('display-mode', 'large');

// Fjern display mode (tilbake til default)
document.documentElement.removeAttribute('display-mode');

// Sjekk nåværende mode
const currentMode = document.documentElement.getAttribute('display-mode');
```

### Responsiv oppførsel

Hver display-mode har innebygd responsiv oppførsel:

- **Mobile mode**: Automatisk større typografi på desktop
- **Large mode**: Konsistent stor typografi på alle skjermstørrelser

### Eksempel på forskjell

```jsx
// Default/Mobile mode (ingen display-mode attributt)
<Heading as="h1">Normal tittel</Heading>
<Text variant="paragraph">Normal tekst</Text>

// Large mode
<div display-mode="large">
  <Heading as="h1">Stor tittel</Heading>
  <Text variant="paragraph">Stor tekst</Text>
</div>
```

### Når skal du bruke det?

- **Default**: Standard responsive typografi for de fleste bruksområder
- **Large**: 
  - Kiosker og informasjonsskjermer
  - Tilgjengelighet for brukere med synsproblemer
  - Presentasjoner og store skjermer
  - Offentlige rom hvor tekst skal være lett å lese

## Oppsummering

Typography Beta gir deg:

1. **Enklere API** - Kun to hovedkomponenter
2. **Bedre tilgjengelighet** - Semantisk korrekt HTML
3. **Større fleksibilitet** - Uendelige kombinasjoner
4. **Konsistent spacing** - Intuitivt "legg til"-system
5. **Fremtidssikkerhet** - Variants som anbefalt styling fra DS

**Husk:** Heading er "strengere" og gir automatisk riktig styling, mens Text er mer fleksibel og krever at du velger variant selv.
