# Typografi Migreringsguide

Denne guiden hjelper deg med å migrere fra de gamle typografi-komponentene til det nye beta typografi-systemet.

## Kom i gang

### Alternativ 1: Automatisk migrering (Anbefalt)

```bash
# Se hva som ville blitt endret (trygt)
npx @entur/typography@latest migrate --dry-run

# Sikker migrering: oppdater kun import paths 
npx @entur/typography@latest migrate

# Komplett migrering: oppdater alt til beta-komponenter
npx @entur/typography@latest migrate --complete

# Vis hjelp og alternativer
npx @entur/typography@latest migrate --help
```

**Oppdater stilene dine:**

```scss
// Erstatt denne
@import '@entur/typography/dist/styles.css';

// Med denne
@import '@entur/typography/src/beta/styles.scss';
```

**Alternativ måte å kjøre migreringsskriptet:**

```bash
# Hvis du har typography-pakken lokalt
yarn workspace @entur/typography migrate --dry-run

# Eller fra typography-mappen
cd packages/typography
yarn migrate --dry-run
```

### Alternativ 2: Manuell migrering

```typescript
// Før
import { Heading1, Paragraph, Link } from '@entur/typography';

// Etter (oppdater komponenter manuelt)
import { Heading, Text, LinkBeta } from '@entur/typography';

// Eksempel på oppdatering:
// <Heading1>Title</Heading1> → <Heading as="h1" variant="title-1">Title</Heading>
// <Paragraph>Text</Paragraph> → <Text variant="paragraph">Text</Text>
```

## Migreringsmodi

### 📝 Sikker modus (standard)
- **Hva det gjør**: Oppdaterer kun import paths
- **Risiko**: Minimal - dine komponenter forblir uendret
- **Når å bruke**: Når du vil migrere gradvis og teste steg for steg

### 🚀 Komplett modus (`--complete`)
- **Hva det gjør**: Oppdaterer både imports og komponentbruk
- **Konsekvenser**:
  - `<Heading1>` blir `<Heading as="h1" variant="title-1">`
  - `<Paragraph>` blir `<Text variant="paragraph">`
  - `<Link>` blir `<LinkBeta>`
  - Props kan trenge oppdateringer
  - Styling-klasser kan endres
- **⚠️ Viktig**: Test grundig etter migrering!

## Hva du får

- **Automatisk migreringsskript**: Skript som automatisk oppdaterer dine imports og komponenter
- **Sikker migrering**: Dry-run modus for å se endringer først
- **Fleksibel tilnærming**: Velg mellom sikker eller komplett migrering
- **Nye funksjoner**: Tilgang til forbedrede typografi-funksjoner

## Sikkerhetsfunksjoner

Migreringsskriptet inkluderer flere sikkerhetsfunksjoner for å beskytte prosjektet ditt:

- **Tillatte mapper**: Skanner kun `src/**`, `app/**`, `components/**`, etc.
- **Blokkerte mapper**: Skanner aldri `node_modules`, `dist`, `.git`, etc.
- **Dry-run modus**: Test endringer uten å modifisere filer ved å bruke `--dry-run`
- **Tilpassbare stier**: Overstyr mapper med `TYPOGRAPHY_MIGRATION_DIRS` miljøvariabel
- **Filtypefiltrering**: Prosesserer kun TypeScript, JavaScript og SCSS/CSS filer

Migreringshjelperne gir drop-in erstatninger for alle gamle typografi-komponenter:

## Migreringsstrategier

### Strategi 1: Gradvis migrering (Anbefalt)

Bruk migreringshjelperne for å gradvis migrere komponentene dine:

```typescript
// Steg 1: Bruk migration helpers
import { Heading1, Paragraph } from '@entur/typography/migration';

function MyComponent() {
  return (
    <div>
      <Heading1>My Title</Heading1>
      <Paragraph>My content</Paragraph>
    </div>
  );
}
```

```typescript
// Steg 2: Senere, migrer til direkte beta-komponenter
import { Heading, Text } from '@entur/typography';

function MyComponent() {
  return (
    <div>
      <Heading as="h1" variant="title-1">
        Min tittel
      </Heading>
      <Text variant="paragraph">Mitt innhold</Text>
    </div>
  );
}

### Strategi 2: Direkte migrering

Hopp over migreringshjelperne og gå direkte til beta-komponenter:

```typescript
// Før
import { Heading1, Paragraph } from '@entur/typography';

// Etter
import { Heading, Text } from '@entur/typography';

// Oppdater komponentbruk
<Heading1>Tittel</Heading1> → <Heading as="h1" variant="title-1">Tittel</Heading>
<Paragraph>Innhold</Paragraph> → <Text variant="paragraph">Innhold</Text>
```

## Vanlige problemer og løsninger

### Problem: CSS-konflikter

**Problem**: CSS-konflikter mellom gamle og nye typografi-stiler.

**Løsning**: Erstatt gamle typografi-stiler med nye beta-stiler:

```scss
// Fjern denne
@import '@entur/typography/dist/styles.css';

// Legg til denne
@import '@entur/typography/src/beta/styles.scss';
```

### Problem: Manglende komponenter

**Problem**: Noen komponenter kan ikke være tilgjengelige i migreringshjelperne.

**Løsning**: Bruk de nye beta-komponentene direkte:

```typescript
import { Heading, Text } from '@entur/typography';
```

### Problem: TypeScript-feil

**Problem**: TypeScript-feil på grunn av prop-forskjeller.

**Løsning**: Sjekk komponentmappingstabellen over og oppdater props tilsvarende.

## Eksempler

### Før migrering

```typescript
import { Heading1, Paragraph, Link, StrongText } from '@entur/typography';

function Article() {
  return (
    <article>
      <Heading1>Article Title</Heading1>
      <Paragraph>
        This is a <StrongText>paragraph</StrongText> with a{' '}
        <Link href="/more">link to more content</Link>.
      </Paragraph>
    </article>
  );
}
```

### Etter migrering (Bruker migreringshjelpere)

```typescript
import {
  Heading1,
  Paragraph,
  Link,
  StrongText,
} from '@entur/typography/migration';

function Article() {
  return (
    <article>
      <Heading1>Article Title</Heading1>
      <Paragraph>
        This is a <StrongText>paragraph</StrongText> with a{' '}
        <Link href="/more">link to more content</Link>.
      </Paragraph>
    </article>
  );
}
```

### Etter migrering (Bruker beta-komponenter)

```typescript
import { Heading, Text, LinkBeta } from '@entur/typography';

function Article() {
  return (
    <article>
      <Heading as="h1" variant="title-1">
        Article Title
      </Heading>
      <Text variant="paragraph">
        This is a{' '}
        <Text variant="emphasized" weight="semibold">
          paragraph
        </Text>{' '}
        with a <LinkBeta href="/more">link to more content</LinkBeta>.
      </Text>
    </article>
  );
}
```

## Beste praksis

1. **Start med migreringshjelpere** for en smidig overgang
2. **Test grundig** etter hvert migreringssteg
3. **Oppdater stiler** for å bruke de nye beta typografi-stilene
4. **Adopter gradvis nye funksjoner** som avstand og størrelsesvarianter
5. **Fjern migreringshjelpere** når du er fullstendig migrert
