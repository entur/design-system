# Typografi Migreringsguide

Denne guiden hjelper deg med å migrere fra de gamle typografi-komponentene til det nye beta typografi-systemet.

## Kom i gang

### Alternativ 1: Automatisk migrering (Anbefalt)

```bash
# Vis hjelp og alternativer
npx @entur/typography@latest migrate --help

# Se hva som ville blitt endret (trygt)
npx @entur/typography@latest migrate --dry-run

# Komplett migrering: oppdater alt til beta-komponenter
npx @entur/typography@latest migrate

# Import-only migrering: oppdater kun import paths 
npx @entur/typography@latest migrate --import-only
```

**Alternativ måte å kjøre migreringsskriptet:**

# Direkte kjøring (krever glob-pakken)

```bash
node node_modules/@entur/typography/scripts/migrate-typography.js --dry-run
```

**Merk**: Hvis du kjører skriptet direkte og får en feil om manglende `glob`-pakke, installer den:
```bash
npm install glob
# eller
yarn add glob
```

### Alternativ 2: Manuell migrering

```typescript
// Før
import { Heading1, Paragraph, Link } from '@entur/typography';

// Etter (oppdater komponenter manuelt)
import { Heading, Text, LinkBeta } from '@entur/typography';

// Eksempel på oppdatering:
// <Heading1>Title</Heading1> → <Heading as="h1" variant="title-1">Title</Heading>
// <Paragraph>Text</Paragraph> → <Text variant="paragraph">Text</Text>
```

## Migreringsmetoder

### 🚀 Komplett migrering (standard)
- **Hva det gjør**: Oppdaterer både imports og komponentbruk til beta-komponenter
- **Konsekvenser**:
  - `<Heading1>` blir `<Heading as="h1" variant="title-1">`
  - `<Paragraph>` blir `<Text variant="paragraph">`
  - `<Link>` blir `<LinkBeta>`
  - Props kan trenge oppdateringer
  - Styling-klasser kan endres
- **Når å bruke**: Når du vil migrere til det nye systemet umiddelbart
- **⚠️ Viktig**: Test grundig etter migrering!

### 📝 Import-only modus (`--import-only`)
- **Hva det gjør**: Oppdaterer kun import paths, beholder eksisterende komponentbruk
- **Risiko**: Minimal - dine komponenter forblir uendret
- **Når å bruke**: Når du vil migrere gradvis og teste steg for steg
- **Fordel**: Du kan oppdatere komponenter manuelt når du er klar

## Hva du får

- **Automatisk migreringsskript**: Skript som automatisk oppdaterer dine imports og komponenter
- **Sikker migrering**: Dry-run modus for å se endringer først
- **Fleksibel tilnærming**: Velg mellom komplett eller import-only migrering
- **Nye funksjoner**: Tilgang til forbedrede typografi-funksjoner
- **Kontrollert spacing**: Alle komponenter har `margin: 0` som standard - du velger når du vil ha spacing

## Sikkerhetsfunksjoner

Migreringsskriptet inkluderer flere sikkerhetsfunksjoner for å beskytte prosjektet ditt:

- **Tillatte mapper**: Skanner kun `src/**`, `app/**`, `components/**`, etc.
- **Blokkerte mapper**: Skanner aldri `node_modules`, `dist`, `.git`, etc.
- **Dry-run modus**: Test endringer uten å modifisere filer ved å bruke `--dry-run`
- **Tilpassbare stier**: Overstyr mapper med `TYPOGRAPHY_MIGRATION_DIRS` miljøvariabel
- **Filtypefiltrering**: Prosesserer kun TypeScript, JavaScript og SCSS/CSS filer

## Migreringsstrategier

### Strategi 1: Komplett migrering (Standard)

Migrer direkte til beta-komponenter med automatisk oppdatering:

```bash
# Komplett migrering (standard)
npx @entur/typography@latest migrate
```

Dette vil automatisk:
- Oppdatere alle imports
- Erstatte gamle komponenter med beta-komponenter
- Konvertere props til det nye formatet

```typescript
// Før migrering
import { Heading1, Paragraph } from '@entur/typography';

function MyComponent() {
  return (
    <div>
      <Heading1>Min tittel</Heading1>
      <Paragraph>Mitt innhold</Paragraph>
    </div>
  );
}
```

```typescript
// Etter komplett migrering
import { Heading, Text } from '@entur/typography';

function MyComponent() {
  return (
    <div>
      <Heading as="h1" variant="title-1">
        Min tittel
      </Heading>
      <Text variant="paragraph">Mitt innhold</Text>
    </div>
  );
}
```

### Strategi 2: Import-only migrering (For gradvis overgang)

Bruk `--import-only` for å migrere steg for steg:

```bash
# Import-only migrering
npx @entur/typography@latest migrate --import-only
```

Dette oppdaterer kun imports og lar deg beholde eksisterende komponentbruk:

```typescript
// Steg 1: Import-only migrering (kun imports)
import { Heading1, Paragraph } from '@entur/typography';

function MyComponent() {
  return (
    <div>
      <Heading1>Min tittel</Heading1>
      <Paragraph>Mitt innhold</Paragraph>
    </div>
  );
}
```

```typescript
// Steg 2: Senere, oppdater komponenter manuelt
import { Heading, Text } from '@entur/typography';

function MyComponent() {
  return (
    <div>
      <Heading as="h1" variant="title-1">
        Min tittel
      </Heading>
      <Text variant="paragraph">Mitt innhold</Text>
    </div>
  );
}
```

## Viktig: Ny margin-oppførsel

### Standard margin-oppførsel

Beta-komponenter har **ingen margin som standard** (`margin: 0`) på base-klassene, men **mange varianter legger til egne margins**:

**Før migrering:**
```jsx
<Heading1>Denne hadde automatisk margin</Heading1>
<Paragraph>Denne hadde også margin</Paragraph>
```

**Etter migrering:**
```jsx
// Med variant som har spacing
<Heading as="h1" variant="title-1">Denne har margin fra variant</Heading>
<Text variant="paragraph">Denne har margin fra variant</Text>

// Uten variant (kun base-klasse)
<Heading as="h1">Denne har ingen margin</Heading>
<Text>Denne har ingen margin</Text>
```

### Hvordan spacing fungerer

```jsx
// Variant med spacing (standard)
<Heading as="h1" variant="title-1">Tittel med margin fra variant</Heading>
<Text variant="paragraph">Tekst med margin fra variant</Text>

// Eksplisitt spacing (overstyrer variant)
<Heading as="h1" variant="title-1" spacing="lg">Tittel med large spacing</Heading>
<Text variant="paragraph" spacing="md">Tekst med medium spacing</Text>

// Uten spacing (kun base-klasse)
<Heading as="h1">Tittel uten margin</Heading>
<Text>Tekst uten margin</Text>

// Fjern spacing fra variant
<Heading as="h1" variant="title-1" spacing="none">Tittel uten margin</Heading>
<Text variant="paragraph" spacing="none">Tekst uten margin</Text>
```

### Automatisk margin → spacing migrering

Migreringsskriptet oppdaterer automatisk `margin` props til `spacing`:

```jsx
// Før migrering
<Heading1 margin="bottom">Tittel</Heading1>
<Paragraph margin="none">Tekst</Paragraph>

// Etter migrering
<Heading as="h1" variant="title-1" spacing="md-bottom">Tittel</Heading>
<Text variant="paragraph" spacing="none">Tekst</Text>
```

**Spacing-mapping:**
- `margin="bottom"` → `spacing="md-bottom"`
- `margin="top"` → `spacing="md-top"`
- `margin="none"` → `spacing="none"`
- `margin="lg"` → `spacing="lg"`
- `margin="sm"` → `spacing="sm"`

## Vanlige problemer og løsninger

### Problem: CSS-konflikter

**Problem**: CSS-konflikter mellom gamle og nye typografi-stiler.

**Løsning**: Erstatt gamle typografi-stiler med nye beta-stiler:

```scss
// Fjern denne
@import '@entur/typography/dist/styles.css';

// Legg til denne
@import '@entur/typography/src/beta/styles.scss';
```

### Problem: Manglende komponenter

**Problem**: Noen komponenter kan være utilgjengelige i migreringshjelperne.

**Løsning**: Bruk de nye beta-komponentene direkte:

```typescript
import { Heading, Text } from '@entur/typography';
```

### Problem: TypeScript-feil

**Problem**: TypeScript-feil på grunn av prop-forskjeller.

**Løsning**: Sjekk komponentmappingstabellen over og oppdater props tilsvarende.

### Problem: Semantic HTML-advarsler

**Problem**: Migreringsskriptet kan vise advarsler om heading-nivåer som ikke matcher.

**Eksempel på advarsel:**
```
Heading component has 'as="h3"' but expected 'as="h4"' - review semantic HTML structure
```

**Løsning**: Gjennomgå heading-strukturen din og oppdater `as` props manuelt for å matche riktig heading-nivå:

```jsx
// Før (kan gi advarsel)
<Heading4 as="h3">Dette kan gi advarsel</Heading4>

// Etter (korrekt semantic HTML)
<Heading4 as="h4">Dette er korrekt</Heading4>
```

## Eksempler

### Før migrering

```typescript
import { Heading1, Paragraph, Link, StrongText } from '@entur/typography';

function Article() {
  return (
    <article>
      <Heading1>Article Title</Heading1>
      <Paragraph>
        This is a <StrongText>paragraph</StrongText> with a{' '}
        <Link href="/more">link to more content</Link>.
      </Paragraph>
    </article>
  );
}
```

### Etter komplett migrering (Standard)

```typescript
import { Heading, Text, LinkBeta } from '@entur/typography';

function Article() {
  return (
    <article>
      <Heading as="h1" variant="title-1">
        Article Title
      </Heading>
      <Text variant="paragraph">
        This is a{' '}
        <Text variant="emphasized" weight="semibold">
          paragraph
        </Text>{' '}
        with a <LinkBeta href="/more">link to more content</LinkBeta>.
      </Text>
    </article>
  );
}
```

### Etter import-only migrering (Med --import-only flagget)

```typescript
import {
  Heading1,
  Paragraph,
  Link,
  StrongText,
} from '@entur/typography';

function Article() {
  return (
    <article>
      <Heading1>Article Title</Heading1>
      <Paragraph>
        This is a <StrongText>paragraph</StrongText> with a{' '}
        <Link href="/more">link to more content</Link>.
      </Paragraph>
    </article>
  );
}
```

## Beste praksis

1. **Bruk komplett migrering som standard** for umiddelbar overgang til beta-komponenter
2. **Test grundig** etter migrering for å sikre at alt fungerer som forventet
3. **Oppdater stiler** for å bruke de nye beta typografi-stilene
4. **Bruk import-only migrering** hvis du trenger mer tid til å tilpasse komponentene
5. **Adopter nye funksjoner** som avstand og størrelsesvarianter når du er klar

## Støtte

Hvis du støter på problemer under migrering:
