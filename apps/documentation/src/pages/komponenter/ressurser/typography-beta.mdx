## Hvorfor et nytt API?

- Styling - visuelt bedre hierarki
- Enklere API – kun to hovedkomponenter å forholde seg til.
- Bedre tilgjengelighet – semantisk korrekt HTML med as-prop.
- Større fleksibilitet – kombiner `as`, `variant`, `size`, `weight` og `spacing` fritt.

## Heading
Heading gir deg riktige styles automatisk, og er laget for å følge designsystemets nivåer.

- Semantikk (`as`): velg riktig HTML-tag (h1–h6)
- Visuelt uttrykk (`variant` eller `size`): styr utseendet uavhengig av semantikk. `variant`er vår anbefalt styling av ulike nivåer, men du kan velge `size` om du ønsker annen størrelse.

### Hvorfor skille as og variant?
Ved å skille mellom semantiske props (`as`) og visuelle props (`variant`, `size`, `weight`, `spacing`), gir vi utviklere mulighet til å skrive semantisk korrekt HTML uten å være bundet til det visuelle uttrykket. Dette gir flere fordeler:

- Universell utforming – skjermlesere forstår innhold bedre
- SEO – søkemotorer tolker strukturen korrekt
- Designfrihet – semantisk `<h2>` kan styles som en liten tittel
- Konsistens – samme variant kan gjenbrukes overalt

## Eksempler

### Standard varianter (anbefalt)

````jsx
<Heading as="h1" variant="title-1">Title 1</Heading>
<Heading as="h2" variant="title-2">Title 2</Heading>
<Heading as="h3" variant="subtitle-1">Subtitle 1</Heading>
<Heading as="h4" variant="subtitle-2">Subtitle 2</Heading>
<Heading as="h5" variant="section-1">Section 1</Heading>
<Heading as="h6" variant="section-2">Section 2</Heading>
````

### Kun semantikk (heading mapper default variant selv)

````jsx
<Heading as="h1">Title 1</Heading>
<Heading as="h2">Title 2</Heading>
<Heading as="h3">Subtitle 1</Heading>
<Heading as="h4">Subtitle 2</Heading>
````

### Bland semantikk og visuell variant

````jsx
<Heading as="h1" variant="section-1">Title 1</Heading>
<Heading as="h2" variant="section-2">Title 2</Heading>
<Heading as="h3" variant="subtitle-1">Subtitle 1</Heading>
<Heading as="h4" variant="subtitle-2">Subtitle 2</Heading>
````

### Manuell size

````jsx
<Heading as="h1" size="2xl">2xl</Heading>
<Heading as="h2" size="xl">xl</Heading>
<Heading as="h3" size="lg">lg</Heading>
<Heading as="h4" size="m">m</Heading>
<Heading as="h5" size="s">s</Heading>
<Heading as="h6" size="xs">xs</Heading>
````

## Text

Text er mer fleksibel, og krever at du velger variant selv.

### Varianter (designsystemets anbefaling)

````jsx
<Text variant="leading">Leading</Text>
<Text variant="quote">Quote</Text>
<Text variant="paragraph">paragraph</Text>
<Text variant="subparagraph">subparagraph</Text>
<Text variant="caption">caption</Text>
<Text variant="label">Label</Text>
<Text variant="sublabel">SubLabel</Text>
<Text variant="overline">Overline</Text>
<Text variant="emphasized">Emphasized</Text>
<Text variant="code-text">Code Text</Text>
<Text variant="preformatted-text">Preformatted Text</Text>
````

### Størrelser og vekt

````jsx
<Text size="xl" weight="bold">Bold</Text>
<Text size="m" weight="semibold">Semibold</Text>
<Text size="m" weight="medium">Medium</Text>
<Text size="s" weight="regular">Regular</Text>

<Text size="m" weight="700">700</Text>
<Text size="m" weight="600">600</Text>
<Text size="m" weight="500">500</Text>
<Text size="m" weight="400">400</Text>
````

### Semantikk 

Husk at det er ditt ansvar å bruke riktig as-prop, slik at HTML-en gir mening for både mennesker, maskiner og hjelpemidler. Default er `as = span`

````jsx
<Text as="p">{'<p>as paragraph</p>'}</Text>
<Text as="label">{'<label>as label</label>'}</Text>
<Text as="code">{'<code>as code</code>'}</Text>
<Text as="pre">{'<pre>as preformatted text</pre>'}</Text>
<Text as="blockquote">{'<blockquote>as blockquote</blockquote>'}</Text>
````

Hvis du bare skriver:

```html
<Text as="label">Navn</Text>
```

…får du et semantisk `<label>` uten styling. Skal den se ut som den kommer fra vårt designsystem, bør du kombinere med en variant:

```html
<Text as="label" variant="label">Navn</Text>
```

## Spacing prop

Spacing kontrollerer mengden luft over og under typografikomponentene. Vi bruker våre [spacing-tokens](/tokens/ovrige-tokens/spacing) fra `xs2` til `xl`. Du kan også spesifisere retningsbestemt spacing med `-top` eller `-bottom` suffiks.

````jsx
// Default spacing (md)
<Heading as="h2" variant="title-1" spacing="md">title 1</Heading>
<Heading as="h2" variant="2xl" spacing="md">2xl</Heading>

<Text variant="m" spacing="md">m</Text>

// Small spacing
<Heading as="h2" variant="title-1" spacing="sm">title 1</Heading>
<Heading as="h2" variant="2xl" spacing="sm">2xl</Heading>

<Text variant="paragraph" spacing="sm">Paragraph</Text>
<Text variant="m" spacing="sm">m</Text>

// Large spacing
<Heading as="h2" variant="title-1" spacing="lg">title 1</Heading>
<Heading as="h2" variant="2xl" spacing="lg">2xl</Heading>

<Text variant="m" spacing="lg">m</Text>

// No spacing
<Heading as="h2" variant="title-1" spacing="none">title 1</Heading>
<Heading as="h2" variant="2xl" spacing="none">2xl</Heading>

<Text variant="m" spacing="none">m</Text>

// Directional spacing
<Heading as="h2" variant="title-1" spacing="lg-top">Large top spacing only</Heading>
<Text variant="paragraph" spacing="sm-bottom">Small bottom spacing only</Text>
<Heading as="h2" variant="title-2" spacing="md-top">Medium top spacing only</Heading>

````

## Display Mode

TypographyBeta støtter forskjellige visninger for å tilpasse typografien til ulike skjermstørrelser og bruksområder. Denne løsninger er foreløpig designet med tanke på automater. Men vil passe flere bruksområder.

### Hvordan det fungerer

Systemet bruker `display-mode` attributtet for å kontrollere typografi-skalering:

- **Default/Mobile**: Responsiv typografi som tilpasser seg skjermstørrelse
- **Large**: Forstørret typografi for store skjermer, kiosker, eller tilgjengelighet

### Bruk av display-mode

#### HTML-nivå (anbefalt for hele siden)

```html
<html display-mode="large">
  <!-- Alt innhold får large typografi -->
</html>
```

#### Komponent-nivå (for spesifikke seksjoner)

```html
<div display-mode="large">
  <Heading as="h1">Stor tittel for store skjermer</Heading>
  <Text variant="paragraph">Større tekst som er lettere å lese</Text>
</div>
```

#### JavaScript (dynamisk endring)

```javascript
// Sett display mode for hele siden
document.documentElement.setAttribute('display-mode', 'large');

// Fjern display mode (tilbake til default)
document.documentElement.removeAttribute('display-mode');

// Sjekk nåværende mode
const currentMode = document.documentElement.getAttribute('display-mode');
```

### Responsiv oppførsel

Hver display-mode har innebygd responsiv oppførsel:

- **Mobile mode**: Automatisk større typografi på desktop
- **Large mode**: Konsistent stor typografi på alle skjermstørrelser

### Eksempel

```jsx
// Default/Mobile mode (ingen display-mode attributt)
<Heading as="h1">Normal tittel</Heading>
<Text variant="paragraph">Normal tekst</Text>

// Large mode
<div display-mode="large">
  <Heading as="h1">Stor tittel</Heading>
  <Text variant="paragraph">Stor tekst</Text>
</div>
```

### Når skal du bruke det?

- **Default**: Standard responsive typografi for de fleste bruksområder
- **Large**:
  - Automater og informasjonsskjermer
  - Tilgjengelighet for brukere med synsproblemer
  - Presentasjoner og store skjermer
  - Offentlige rom hvor tekst skal være lett å lese

## Migrering

Her er mappinga av alle gamle komponenter → nye.

### Tittel komponenter → Heading

```html
Heading1 → <Heading as="h1" variant="title-1">
Heading2 → <Heading as="h2" variant="title-2">
Heading3 → <Heading as="h3" variant="subtitle-1">
Heading4 → <Heading as="h4" variant="subtitle-2">
Heading5 → <Heading as="h5" variant="section-1">
Heading6 → <Heading as="h6" variant="section-2">
BaseHeading → <Heading>
```

### Tekst komponenter → Text

```html
Paragraph → <Text as="p" variant="paragraph">
LeadParagraph → <Text as="p" variant="leading">
SmallText → <Text as="p" variant="subparagraph">
StrongText → <Text as="strong" weight="bold">
EmphasizedText → <Text as="em" variant="emphasized">
CodeText → <Text as="code" variant="code-text">
PreformattedText → <Text as="pre" variant="preformatted-text">
Label → <Text as="label" variant="label">
SubLabel → <Text as="span" variant="sublabel">
SubParagraph → <Text as="p" variant="subparagraph">
```
