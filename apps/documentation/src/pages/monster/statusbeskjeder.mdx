  return <SEO title={props.pageContext.frontmatter.title} description={props.pageContext.frontmatter.description} pathname={props.pageContext.frontmatter.route} />

export const query = graphql`
  query {
    files: allFile(
      filter: {
        sourceInstanceName: { eq: "downloads" }
        relativePath: { glob: "illustrations/**" }
        extension: { eq: "svg" }
      }
    ) {
    images: nodes {
      name
      publicURL
      relativePath
    }
    }
  }
`;

Statusbeskjeder informerer brukeren når noe går galt, eller når det ikke finnes innhold å vise. De består ofte av en illustrasjon, en kort forklarende tekst og eventuelt en handlingsmulighet.

<BannerAlertBox title="Informasjon" variant="information">Denne siden er under arbeid. Det som står her er det Entur appen bruker. Om du har innspill til mer standardisert innhold her, ta kontakt med oss! </BannerAlertBox>

## Statusbeskjeder og illustrasjoner

Her presenteres en liste over illustrasjoner som blir brukt for ulike statusbeskjeder. Du finner nedlasting av illustrasjonene på [denne siden](/identitet/verktoykassen/illustrasjoner).

Illustrasjonene finnes også som animasjoner. Disse ligger i Google Drive i mappen `DesignGuild/Illustration Library/Animations/Animasjoner Entur`.
