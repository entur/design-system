## Oppbygning
- `Template.Portal` lager grid med to kolonner og full høyde.
- `Template.Portal.Sidebar` og `Template.Portal.Main` brukes som direkte barn av `Template.Portal`.
- `Template.Portal.Sidebar` er `aside` i kontrast; seksjonene `Template.Portal.Sidebar.Logo`, `Template.Portal.Sidebar.User`, `Template.Portal.Sidebar.Data`, `Template.Portal.Sidebar.Navigation` og `Template.Portal.Sidebar.Footer` er valgfrie.
- `Template.Portal.Main` er `main` med standard padding for innhold.

## Tilpasning
- Bredde på sidefeltet kan overstyres med CSS-variabelen `--eds-sidebar-width` (standard `20rem`).
- Padding på hovedinnholdet kan overstyres med CSS-variabelen `--eds-portal-main-padding` (standard `1rem`).

```css
.portal {
  --eds-sidebar-width: 20rem;
  --eds-portal-main-padding: 1rem;
}
```
