}

export const query = graphql`
query komigang {
  imagefiles: allFile(filter: {sourceInstanceName: {eq: "media"}, relativeDirectory: {glob: "images/ressurser"}, extension: {eq: "png"}}) {
    images: nodes {
      name
      childImageSharp {
         gatsbyImageData(
          layout: CONSTRAINED
        )
      }
    }
  }
}
`;

Vi har satt sammen et sett med maler og metoder vi tror er spesielt relevant for arbeidet i Entur slik at de er tilgjengelig for alle. Målet er å finne de verktøyene som hjelper oss å oppnå målene våres og samarbeide enklere i og på tvers av team og fagdisipliner.

Metodene er hentet og tilpasset på fra ulike kilder innen digital produktutvikling og interaksjons- og tjenestedesign. Noen gode kilder man kan se på hvis man er mer interessert:
